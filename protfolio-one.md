# Portfolio One Live Preview

Portfolio One is the active Smartgen theme for this project. The preview below is built from the plugin directory and published alongside the generated showcase.

[Open the live Portfolio One preview](protfolio-one/index.html)

The theme is configured from `protfolio-one/smartgen-material.yml` and `protfolio-one/runtime/theme.config.yml`. Styles, tokens, effects, motion modules, and extension hooks are all published with the preview so the complete plugin behavior can be inspected in the browser.

[View the plugin source](https://github.com/bayeziddev/Material-smartgen/tree/main/protfolio-one)
